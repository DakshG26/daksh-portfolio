🏆 Hacktober Hackathon · Local AI

Automated Documentation Drift Detection System

Built in an intense 8-hour hackathon sprint. Automatically detects and flags semantic drift between source code changes and their technical documentation using local LLM inference and vector embeddings. Zero cloud dependency — all inference runs on-device via Ollama. Solves the classic "stale docs" problem with a pipeline that diffs code commits, re-embeds changed symbols, and alerts when docs fall out of sync.
